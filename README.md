# ☕ Green Coffee – A Modern E-commerce Coffee Shop

Green Coffee is a complete e-commerce website built for a premium coffee brand. It allows users to browse and purchase coffee products, while the admin panel offers full control over product listings, user data, and order tracking.

---

## 🚀 Features

- 🛍️ Product catalog with detailed listings
- 🔐 User authentication (login/register)
- 🛒 Add to cart and checkout system
- 📦 Admin dashboard to manage products, users, and orders
- 📧 Contact form (optional)
- 🔎 Search and filter functionality

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Tools:** XAMPP, phpMyAdmin
